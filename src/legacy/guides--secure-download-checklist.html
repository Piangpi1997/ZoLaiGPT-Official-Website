A checklist for safer software downloads

Before you open an APK or archive, verify where it came from, which release it belongs to and what your device is asking you to approve.

Before you download

  1. Start at the publisher’s site. Use a bookmark or enter the domain yourself. Check the address bar before entering sign-in details or following a link shared in a chat.
  2. Open the specific release. Check its platform, version and channel. Look for release notes and a published checksum. Beta and debug-signed builds are intended for testing and may have different installation requirements.
  3. Record the exact filename and SHA-256. Compare values from the same release. If there is a choice between a source ZIP and an APK, the APK is the installable Android package.

Verify the file you actually received

Wait for the download to finish, then choose the file from Downloads in a SHA-256 checker. Compare the full 64-character value against the publisher’s value. An exact match confirms that the bytes agree with the published checksum. The publisher’s identity and the software’s safety still need their own checks.

If the hashes differ, leave the file unopened and delete it. Check whether the publisher just posted an update, then download the intended version again. If the mismatch persists, report the filename and computed hash to the publisher.

Read the installation prompts before accepting

Keep Play Protect enabled on Android. If you choose to install a verified APK and Android asks to allow installs from your browser or file manager, grant access only to the app that opens the APK and turn that access off afterward. If Android or Play Protect blocks the install, read the warning and check with the publisher before continuing.

If an update reports a signing conflict, check the publisher’s instructions and back up the app’s data before considering an uninstall. An app name and icon alone cannot establish that two APKs come from the same publisher.
