Typing in Myanmar and Zomi (Tedim) on Android

Myanmar needs its own keyboard; Zomi (Tedim) needs only the English one. Set both up once and switch between them with one tap.

How to use this guide: This educational text was prepared with AI assistance and reviewed against the linked reference materials. It explains keyboard setup on Android. It is not a verified translation, and Tedim spelling should be checked by a fluent speaker. Report corrections by email.

Two scripts, two keyboards

Typing in Myanmar and Zomi (Tedim) on Android means dealing with two different writing systems. Myanmar (Burmese) is written in the Myanmar script, and it needs a Myanmar keyboard. Zomi (Tedim) is written with the Latin alphabet — the same letters as English — so it needs no special script, only the ordinary English keyboard. Many people in Myanmar use both every day, sometimes in the same message, so the real skill is switching keyboards quickly and knowing which script you are actually typing in.

This guide uses Gboard, Google's keyboard, because it is installed on most Android phones and supports both. The steps are similar on other keyboards, but menu names may differ.

Adding the Myanmar keyboard with Gboard

If your phone shows English letters when you tap a text box, the Myanmar keyboard has not been added yet. Add it once and it stays:

  1. Open Settings on your phone.
  2. Go to System, then Languages & input, then On-screen keyboard. (On some phones the path is Settings → General management → Keyboard list and default, or Settings → Additional settings → Keyboard & input method.)
  3. Tap Gboard, then Languages, then Add keyboard.
  4. Find Myanmar (Burmese) — listed as မြန်မာ — and tap it, then tap Done.
  5. Open any app with a text box, tap the text box, and check that a globe key or language key now appears on the keyboard.

If you cannot find "Languages & input" in Settings, open the Gboard app itself from your app list — its settings screen has the same "Languages" option. If Gboard is not installed, you can get it from the Play Store; it is free.

Switching between keyboards

Once two or more keyboards are added, switching takes one tap. On Gboard, tap the globe key (🌐) on the bottom row to switch to the next language, or long-press the globe key to see the full list and pick one. Some phones show a small keyboard icon in the navigation bar instead — tapping that opens the same chooser.

A practical habit: before you start typing an important message, glance at the space bar. Gboard shows the current language name there — "English" or "မြန်မာ". If it says the wrong one, you will type a whole sentence in the wrong script before you notice. Checking the space bar takes one second and saves retyping the whole message.

Myanmar Unicode, not Zawgyi

Myanmar text on Android comes in two encodings: Unicode and Zawgyi. Unicode is the modern standard — it is what Android, the web and new apps expect. Zawgyi is an older, non-standard encoding that was common years ago. Text typed in Zawgyi looks correct on a phone that has Zawgyi fonts, but on a modern phone or website it can appear as broken, jumbled or unreadable characters.

Use Myanmar Unicode. Gboard's Myanmar keyboard types Unicode. If you receive a message that looks broken — letters in the wrong order, or boxes where letters should be — the sender probably used Zawgyi. You cannot fix their message from your side, but you can avoid creating the same problem: keep your keyboard on Unicode, and if an app you use offers a "Zawgyi" keyboard option, do not choose it. All Myanmar example sentences in these guides are written in standard Myanmar Unicode.

One more thing to check: some older apps and websites still display Zawgyi by default. If Myanmar text looks wrong in one app but fine everywhere else, the problem is that app's font settings, not your keyboard.

Typing Zomi (Tedim)

Zomi (Tedim) is written with the Latin alphabet, so you type it with the English keyboard — no extra keyboard to install. Type it the way it sounds, using ordinary Latin letters. If your spelling needs an accented letter, long-press the base letter on Gboard to see accented options, then slide to the one you want.

Two points matter here. First, Tedim and Burmese are different languages. Typing a Burmese sentence and calling it Zomi is wrong — it is Burmese, whatever script you used. Second, Tedim spelling is not yet fully standardised in the way English spelling is, so if you are writing for other people, ask a fluent Tedim speaker to check important text. No translation on this site is presented as a verified Tedim translation without that kind of review.

Voice input and handwriting

Gboard can also type for you. Tap the microphone key and speak — Gboard's voice typing supports English and Myanmar, though accuracy depends on background noise and your accent, so always read the result before sending. For Myanmar, Gboard also offers handwriting input: switch to the handwriting layout and draw each character with your finger. Handwriting is slower, but it is useful when you know how a character looks and cannot remember which key it is on. Availability of voice and handwriting input varies by device and by the language you have selected, so if an option is missing, check that the language is added in Gboard's language settings first.

Common problems

  • The keyboard does not appear: tap the text box again, then check that Gboard is set as your default keyboard in Settings → Languages & input → On-screen keyboard.
  • The wrong script appears: check the language shown on the space bar and tap the globe key to switch. If the language you want is missing, add it in Gboard → Languages.
  • Boxes or blank squares instead of letters: the app or website does not have a font for that script. Try the same text in another app; if it works there, the first app is the problem, not your keyboard.
  • Autocorrect keeps changing your words: autocorrect is trained mostly on English. When you type Tedim words, Gboard may "correct" them into English words. Turn off auto-correction for the English keyboard in Gboard → Text correction, or add your Tedim words to the personal dictionary so they are left alone.
  • Mixed-language messages get messy: switch keyboards at the sentence boundary, not in the middle of a word. One sentence in one script, then switch, then the next sentence.
