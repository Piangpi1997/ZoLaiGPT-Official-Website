# ZoLaiGPT V5.7 — Spatial Glass Chat Preview

21 October 2026 · Preview source and static export prepared. Production release is not approved.

## Delivered implementation

The existing orange orb homepage now links to a dedicated `/chat/` workspace. The workspace uses Next.js App Router, React, Tailwind CSS, Framer Motion and Lucide, with local Inter and JetBrains Mono fonts. The original homepage remains HTML/CSS/JavaScript and retains English, Myanmar and Zomi content.

The new interface includes an atmospheric obsidian background, restrained amber/cyan/violet light, optical glass edges, a collapsible desktop sidebar, native mobile sidebar dialog, source-mode selector, starter cards, bounded local threads and search. User messages, Markdown replies and a prewritten syntax-colored JavaScript example render in the conversation view. The composer supports multiline entry, Enter/Shift+Enter, Ctrl/Cmd+K focus, local text attachments, simulated progressive replies and Stop/Replay controls.

Additional controls include code/reply copy, workspace-link copy excluding messages, Markdown transcript download, an editable canvas with notes export, local feedback, browser read-aloud when supported, and session-only still/solid-surface preferences. Waveform animation is explicitly visual only; no microphone is captured. Web search and live model choices are explicitly unconnected.

## Honest AI and data scope

Responses are prewritten/source-driven local simulations. There is no live OpenRouter or other model integration in this package. No imaginary model names, Pro subscription or release/download promises are added. New UI labels remain English; original Myanmar/Zomi reply content is reused without newly invented translations. Thread/notes/attachment state lives in memory and clears on refresh; maximum 30 threads and 80 messages per thread. The attachment control does not provide AI analysis.
