# V5.7 static preview deployment

Preview only. Do not merge to main, change production branch mapping or attach the official production domain.

## Ready-to-serve package

Extract `ZoLaiGPT-V5.7-Spatial-Glass-CHAT-PREVIEW.zip`. The root contains the multilingual homepage and legal assets; `chat/` contains the complete static Next.js workspace export. The source project and lockfile are included in `chat-workspace/`. node_modules, .next and unused legacy globe/vendor data are excluded.

Serve the extracted root with:

```sh
python3 -m http.server 8080
```

Open http://localhost:8080/chat/ for the workspace and http://localhost:8080/ for the official-site preview. Opening index.html with file:// is unsupported. The workspace assets require serving the root, not serving chat/ as a standalone root, because asset URLs use the /chat base path and shared /assets/logo resources.

## Cloudflare preview

The GitHub source branches are `feature/v57-spatial-chat-preview` and the existing preview ref `feature/v56-liquid-glass-preview`. Both contain the same application revision. Draft PR: https://github.com/Piangpi1997/ZoLaiGPT-Official-Website/pull/3

The established project is `zolaigpt-official-website`. Keep `main` as its production branch. Use branch-preview deployment only. The package includes compiled files, so a static root deployment needs no Next.js server or runtime build. Confirm the generated deployment's exact commit before browser acceptance testing. No new deployment URL is asserted until Cloudflare reports a successful build and the new workspace is visibly served.

If using Direct Upload, upload the extracted root to a dedicated preview project rather than the production environment. Keep `_headers` at the root. The current run could not independently perform a direct upload because the Cloudflare connection returned internal errors; browser dashboard fallback needs user permission.

## Rebuild after source edits

```sh
cd chat-workspace
npm ci
npm run build
npm test
```

Replace the root `chat/` contents with `chat-workspace/out/`, then commit the source and export together to the preview branch. Do not commit node_modules, .next or credentials. If a local Turbopack cache reports a persistence database error, remove only the disposable chat-workspace/.next cache and rebuild.
