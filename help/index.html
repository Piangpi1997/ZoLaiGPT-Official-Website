Is this connected to live AI?+

Not yet. The workspace uses prewritten replies to demonstrate the interface. It cannot answer arbitrary questions with AI.

Which languages can I use?+

The website supports English and Myanmar. The chat demo also includes Zomi (Tedim) source-based sample replies.

Do I need an account or a subscription?+

No account or payment is needed for the public demo and local tools. No paid plans are currently offered.

Where are conversations stored?+

Demo conversations stay in the current tab memory and clear when you refresh. Export Markdown before leaving if you want a copy.

Can I analyse a document or image?+

AI document analysis, image understanding and live web research are Coming Soon. Local text attachments demonstrate the UI only.
