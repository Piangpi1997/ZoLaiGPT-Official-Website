How to use the ZoLaiGPT website

ZoLaiGPT is a browser-based information and learning experience focused on multilingual AI. Here is where to find its most useful features and how to interpret the limits of its current chat demonstration.

Website-only: You do not need an Android app, an installer, a payment account or a subscription to read this website. English articles were prepared with AI assistance; Zomi (Tedim) passages are incomplete and should not be treated as expert-reviewed translations.

1. Start at the homepage

Visit the official ZoLaiGPT homepage. The header introduces the website, the purpose section explains the project, and the learning section links to English articles. You can use the menu to jump directly to Features, About, Guides, Updates, and Contact. The visual orb is a brand illustration: it does not make the website a downloadable application.

On a narrow Android or iPhone screen, open the navigation menu using the menu control near the top. On larger screens the navigation appears as standard links. The layout is designed to work without installing additional software.

2. Choose a language carefully

The language selector includes English, Myanmar (Burmese), and Zomi (Tedim). Selecting one changes supported interface labels and certain main-page explanations. However, not every learning article has been translated. The long-form guides are currently written in English, and some Zomi text uses English fallback while fluent-speaker review is pending.

Look for the language-review notice when switching. When a sentence is in English, treat it as English even if the Zomi option is selected; do not assume the text is a native-reviewed Zomi translation. For topics that affect health, safety, money or law, check trusted primary sources.

3. Browse the learning guides

Visit the Learning Guides collection to read practical explanations about multilingual AI quality, evaluating language-specific answers and editorial transparency. Each guide has a title and readable sections, and you can navigate back to the collection or homepage. These pages are free educational material and do not ask you to buy credits.

4. Understand the optional chat preview

The homepage has a Preview AI panel with common questions. Its messages are generated by a local scripted demo based on known site copy. It is not connected to a live AI model, and it cannot reliably answer arbitrary research questions. The separate browser chat workspace similarly demonstrates local threads and source-based example replies; it should not be mistaken for an unlimited AI assistant.

You can ask the demo about website languages or the project mission, but treat other results as demonstrations only. Do not enter passwords, payment details or private API keys in demo messages. The simple homepage chat keeps its messages in the open browser tab; it is not a private communications service.

5. Follow updates without invented promises

Use the Updates section for notices that are actually confirmed by the site operator. The website does not offer an Android app download, an APK, premium app plan checkout or paid AI subscription. A future announcement should name the feature and its availability clearly before visitors can rely on it.

6. Send useful feedback

If a link is broken or a translation looks wrong, use the site's contact section or send a message to the public contact email. Include the exact page URL, the wording that should be checked, the chosen language and the device/browser you were using. Avoid sending passwords or financial information.

7. Understand what the website stores

The homepage stores your selected language and dismissed-announcement preference in your browser's local storage, so they can persist between visits on that device. The website uses Cloudflare Pages for delivery. Read the Privacy Policy (currently a draft) for the available data-handling information. If you use an external social-media link, the external provider's rules apply.

In short: ZoLaiGPT is an independent learning website. It has multilingual interface options, English educational guides and an optional local chat demonstration. No app installation, account purchase or paid AI feature is required to browse it.
